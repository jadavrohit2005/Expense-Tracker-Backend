# Expense Tracker Backend

A RESTful backend API for managing personal expenses, built using **Node.js, Express.js, MongoDB, and Mongoose**.

This project provides APIs to create, view, update, and delete expenses and helps manage expense data efficiently.

## 🚀 Features

- Add new expenses
- View all expenses
- View a single expense
- Update expenses
- Delete expenses
- RESTful API
- MongoDB database integration
- Mongoose for database management
- Express.js server
- Environment variable configuration
- CORS support

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- REST API
- dotenv
- CORS
